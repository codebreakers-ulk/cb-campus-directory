# Campus Resource Directory

A curated, accessible index of campus resources, tech groups, academic tools, and developer opportunities.

Built with **vanilla HTML, CSS, and JavaScript**. Hosted by **Codebreakers** to introduce students to real-world open-source contributions.

---

## Getting Started Locally

No dependencies, node modules, or build tools required.

1. Fork and clone this repository:
   ```bash
   git clone https://github.com/<your-username>/cb-campus-directory.git
   cd cb-campus-directory
   ```



## Browser Troubleshooting

### How to open the project
1. Find the `index.html` file in the project folder.
2. Right-click the file, choose **Open with**, then pick **Chrome**, **Firefox**, or **Edge**.

### Page not updating or styles look wrong?
Your browser may be showing an old cached version. Hard-refresh the page to fix it:
- **Windows / Linux:** press `Ctrl + F5`
- **Mac:** press `Cmd + Shift + R`
